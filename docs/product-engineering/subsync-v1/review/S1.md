### Should-fix

- **F1** · security · `src/subsync/cli.py` · confirmed: control characters in file names (ESC/BEL, OSC 52) reached the terminal raw through stage lines, summary, error blocks, `-v` tracebacks and debug logs.
- **F2** · security · `src/subsync/writer.py` · unconfirmed (needs a hostile co-user and a won race): the temp file's mode was set by path after close and the hard-link publish followed symlinks.
- **F3** · architecture, conventions · `src/subsync/transcriber.py`, `cli.py`: two drifted copies of the "exception → one-line reason" rule; a message-less Whisper error read "Couldn't load model 'tiny': .".
- **F4** · architecture · `src/subsync/pipeline.py`: the output format reached `generate()` twice (`plan.fmt` and `fmt`), so S5's `-o` inference could name and render differently.
- **F5** · architecture · `src/subsync/pipeline.py` · unconfirmed: stage events lived in the Whisper-importing module, leaving S4 no clean place to show the URL source line before the pre-check.
- **F10** · conventions · `src/subsync/output.py`: an unlistable output folder silently skipped the U1 pre-check.
- **F11** · intent · `src/subsync/transcriber.py`: a cancelled or failed first model download left a partial file, so the next run skipped the one-time notice (R7) while re-downloading silently.
- **F12** · intent · `src/subsync/sources.py`: a symlinked input wrote next to, and was named after, the symlink's target (R14).
- **F13** · intent · `tests/test_cli_integration.py`: the P2 no-warning headline "✓ Subtitles written" was asserted nowhere.
- **F14** · intent · `src/subsync/output.py`: the F4 hint suggested `--format vtt`, which S1 rejects.

### Nits

- F6 · architecture: F11/F20 texts built in several places.
- F7 · architecture, conventions: two `HH:MM:SS` formatters; `_clock` meant different formats in two modules.
- F8 · conventions: the processor's self-check logged at ERROR, leaking a raw log line into non-verbose output.
- F9 · architecture: `main` ignored `args.command`.
- F17 · conventions: inert `noqa`/`type: ignore`, bare generics, the one-file-per-module rule not updated.
- F18 · architecture: model names listed in both `catalog.py` and `transcriber.py`.
- F19 · conventions: `pairwise`/`suppress` idioms, implicit type alias, a missing nested docstring.

### Unconfirmed questions

- F15 · intent · `src/subsync/transcriber.py`: does Ctrl+C while loading a large cached model (Whisper reads and hashes the whole checkpoint) exceed E8's 2 s? A replica measured 1.07 s at turbo size and 2.09 s at large-v3 size. Settled by measuring in S1.8.
- F16 · intent · `src/subsync/cli.py`: F9 (no audio / unreadable) pays the ML import (1.1–1.7 s). The spec's wording on where that import may happen is inconsistent; a question for Igor.
